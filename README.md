# AI-And-ML
This repository contains two beginner-friendly AI/Machine Learning projects focused on simple prediction tasks using supervised learning techniques.

🔹 Project 1: Height Prediction Based on Weight

An AI-trained regression model that predicts a person’s height based on their weight.

Dataset: Height_Weight.csv

Model Type: Regression

Objective: Understand the relationship between physical attributes and apply basic ML concepts.

🔹 Project 2: Marks Prediction Based on Study Hours

A machine learning model that predicts a student’s marks (out of 200) based on the number of hours studied.

Dataset: Hour_Mark.csv

Model Type: Regression

Objective: Analyze how study time impacts academic performance.

🛠️ Technologies Used

Python

Pandas

NumPy

Matplotlib / Seaborn (for visualization)

Scikit-learn

Jupyter Notebook

🎯 Purpose

These projects are designed to strengthen fundamental concepts of:

Data preprocessing

Exploratory Data Analysis (EDA)

Model training and evaluation

Real-world prediction problems
